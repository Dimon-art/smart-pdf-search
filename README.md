# Умный поиск на страницах

Семантический поиск по PDF: ищет не по буквам, а **по смыслу**.  
Подсвечивает найденное прямо в документе и позволяет заменить текст — всё в браузере.

![Главный экран](docs/screenshots/1-main.png)

---

## Возможности

- **Поиск по смыслу** — «штраф за просрочку» найдёт «пени за несвоевременную оплату»
- **Мультиязычность** — запросы на русском находят английский текст и наоборот
- **Подсветка в PDF** — найденные фрагменты выделяются жёлтым на странице
- **Замена текста** — выбор конкретных совпадений и подстановка нового текста
- **Скачивание** — отредактированный PDF доступен сразу после замены
- **Работа с любым PDF** — загрузка своего документа до 100 МБ

## Как это работает

```
PDF  →  чанки  →  эмбеддинги  →  FAISS  →  поиск  →  подсветка  →  замена
 │         │           │              │
 │         │           │              └─ быстрый векторный поиск по 493+ чанкам
 │         │           └─ модель paraphrase-multilingual-MiniLM-L12-v2
 │         └─ разбивка по 500 слов с перекрытием 100
 └─ извлечение текста с координатами каждого блока (bbox)
```

**Стек:**

- **PyMuPDF** — извлечение текста с координатами
- **sentence-transformers** — эмбеддинги (мультиязычная модель)
- **FAISS** — векторный поиск
- **FastAPI** — HTTP-сервер
- **PDF.js** — рендеринг PDF и подсветка на фронтенде

## Быстрый старт

### Через Docker (рекомендуется)

```bash
git clone https://github.com/Dimon-art/smart-pdf-search.git
cd smart-pdf-search
docker compose up -d
```

Открыть **http://localhost:8000**

При первом запуске модель эмбеддингов скачается автоматически (~470 МБ).  
Дальше контейнер переиспользует кэш — стартует за 3–5 секунд.

Полезные команды:

```bash
docker compose logs -f      # логи
docker compose down         # остановить
docker compose up -d        # запустить в фоне
```

**Требования:** Docker Desktop с WSL 2.

---

### Вручную (для разработки)

**Требования:**

- Python **3.10+**
- ~1 ГБ свободного места (модель эмбеддингов ~470 МБ)
- Git

**Установка**

```bash
# Клонировать
git clone https://github.com/Dimon-art/smart-pdf-search.git
cd smart-pdf-search

# Создать окружение
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # macOS / Linux

# Установить зависимости
cd backend
pip install -r requirements.txt

# Из папки backend
uvicorn main:app --reload --port 8000
```

Открыть **http://127.0.0.1:8000**

При первом запуске модель эмбеддингов скачается автоматически (~470 МБ).  
Дальше сервер работает с кэшированным индексом — стартует за 3–5 секунд.

## API

| Метод | Путь | Назначение |
|-------|------|-----------|
| `GET` | `/` | Отдаёт фронтенд |
| `POST` | `/search` | Семантический поиск. Body: `{"query": str, "top_k": int}` |
| `POST` | `/upload` | Загрузить PDF. Multipart-форма |
| `GET` | `/status` | Статус обработки и имя активного PDF |
| `POST` | `/find_matches` | Все вхождения текста в PDF. Body: `{"old_text": str}` |
| `POST` | `/replace` | Заменить выбранные совпадения. Body: `{"old_text": str, "new_text": str, "selected_ids": [int]}` |
| `GET` | `/static/current.pdf` | Активный PDF |
| `GET` | `/static/edited.pdf` | PDF после замены |

## Ограничения

- **Только PDF** с текстовым слоем. Сканы без OCR не поддерживаются.
- **Замена текста** — только для простых текстовых блоков. Шрифт подставляется Helvetica, размер подбирается автоматически.
- **Не работает** с формулами, таблицами и встроенными изображениями.
- **Лимит размера** — 100 МБ на файл.
- **Один активный PDF** за раз (мультизагрузка в roadmap).
