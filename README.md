# Умный поиск на страницах

Семантический поиск по PDF с подсветкой найденного и заменой текста.

## Скриншот
[картинка]

## Что умеет
- Ищет по смыслу (не по буквам) — русский и английский
- Подсвечивает найденное прямо в PDF
- Заменяет текст в выбранных фрагментах
- Скачивает отредактированный PDF

## Технологии
- PyMuPDF (парсинг)
- sentence-transformers (эмбеддинги)
- FAISS (векторный поиск)
- FastAPI (backend)
- PDF.js (frontend)
